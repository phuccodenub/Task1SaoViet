## 3. Kế hoạch tiếp theo (theo thứ tự bắt buộc)

### T+0 → T+1 ngày — Validate trước khi bật bất cứ cái gì

1. **[Dev/Ops]** Bootstrap DB: `scripts/bootstrap.ps1` hoặc `bootstrap.sh`. Ba lưu ý theo thứ tự quan trọng:
   - **Unique index dedupe (R2)**: nếu DB đã có `content.drafts` từ vòng trước và chưa có `ux_content_drafts_variant`, script sẽ tạo index và fail nếu dữ liệu hiện có đã có duplicate `(item_id, platform, variant_key)`. Kiểm trước bằng:
     ```sql
     SELECT item_id, platform, variant_key, COUNT(*) FROM content.drafts GROUP BY 1,2,3 HAVING COUNT(*) > 1;
     ```
     Nếu có duplicate → dedup thủ công trước khi tạo index.
   - **Backfill legacy NULL (Y1)**: nếu DB đã chạy workflow trước vòng V (không có `locked_at`/`queued_at` hoặc chạy ngoài schema hiện tại), `02-content-schema.sql` giờ tự chạy 2 block `UPDATE ... WHERE ... IS NULL` idempotent ngay sau `ADD COLUMN IF NOT EXISTS`. Output sẽ log `UPDATE <N>` rồi lần chạy kế tiếp `UPDATE 0` — đây là hành vi đúng. Nếu N > 0 → có row legacy, nên chạy query audit `SELECT status, COUNT(*) FILTER (WHERE locked_at IS NULL) FROM content.items WHERE status IN ('fanning_out','batch_rewriting') GROUP BY status;` để xác nhận còn 0 sau backfill.
